01 / Yönetici özeti ve kesin karar
Ürün: YarınLab, 6-8. sınıf öğrencilerinin iklimle bağlantılı kararlar verdiği, sonuçlarını ortak bir şehir simülasyonunda
gördüğü ve geri bildirim aldığı web tabanlı eğitim oyunudur. Görsel yaklaşım modern 2.5D izometrik olarak
kesinleştirilmiştir.
Teknik karar: Phaser 4.2.1 + React + TypeScript + Vite; Tiled JSON haritalar; Kenney Isometric Tiles
ailesi; önce yerel senaryolar, ardından güvenli sunucu üzerinden yapay zekâ.
Çalışan prototipin omurgası
 • 32 × 32 izometrik okul/şehir haritası ve dört aktif erişim noktası: Okul, Kantin, Enerji, Atık.
 • Tam çalışan Son Tabak / Kaybolan Öğünler kararı: seçenek  simülasyon  kaynak değişimi  açıklama  karşılaştırma.
 • Gıda israfı ile atık yönetimi arasında en az bir çapraz-modül etkileşimi.
 • Karar gerekçesi ve öğrenme sonucu toplayan, başlangıçta yerel saklamalı öğretmen ekranı.
 • Canlı yapay zekâ kesilse bile çalışabilen doğrulanmış görev ve açıklama yedeği.
 
Kapsam kilidi
COP31 son başvuru: 2 Kasım 2026, 23.59. Final: 15-16 Kasım 2026; 24 saat geliştirme, 5 dakika sunum + 3 dakika
soru-cevap. Başvuruda prototip zorunlu değil; finalde kritik işlevin çalışması ve saha görevi önemli [K1].

07
06 / Asset indirme, dönüştürme ve kalite kontrolü
Adım adım varlık işleme
 • Üretici sayfasını aç; “Download” üzerinden arşivi indir. Gerekiyorsa bağış penceresindeki ücretsiz devam yolunu kullan.
 • İndirilen ZIP dosyasını design/third_party/kenney/ klasörüne aç. ZIP ve lisans dosyasını orijinal tut.
 • Paket içindeki tilemap.txt ve örnek haritalardan gerçek sprite/tile ölçülerini öğren [R7]. Önceden rastgele 128×64
 varsayma.
• Özel objelerin arka planını şeffaf PNG olarak kaydet; isimlerini İngilizce ASCII ve tireli standarda göre düzenle.
 • Kare ikonlar için 128×128 kaynak kullan, arayüz içinde daha küçük boyutlarda göster. Görsellerde metin gömme, metni
 React içinde tut.
• Her paketi önce örnek haritada karşılaştır: perspektif, gölge, renk, piksel yoğunluğu ve telif etiketi uyumunu kontrol et.
 • Tileset çok sayıda küçük dosyadan oluşuyorsa atlası TexturePacker benzeri bir yöntemle veya basit build adımıyla
 birleştir; dosya numaraları için manifest üret.
Asset manifest örneği
 {
  "id": "building_school",
  "file": "/assets/custom/school.png",
  "source": "custom-compatible-art",
  "license": "team-owned",
  "anchor": {"x": 0.5, "y": 1},
  "tileFootprint": [3, 3],
  "interactive": true
}
Kaynak paketlerin görselleri PDF içine kopyalanmamıştır; bağlantılar doğrudan hak sahibinin sayfasına gider. Harita ve
ekran çizimleri bu doküman için hazırlanmış şematik tasarım çizimleridir.

16 / Veri modeli - çalışan karar motoru sözleşmesi
Her görev version id ve başlangıç koşulu taşır. Senaryo sonuçları elle kodlanmış bir durum tablosu olabilir; daha sonra
bilimsel modelle değiştirilir. Farklı oynama oturumlarının karşılaştırılabilirliği için aynı seed ve koşullar saklanır.
 type Resources = {
  budget: number;      // oyun puanı; gerçek para değil
  foodWasteKg: number; // senaryoda ölçülen/tahmini kg
  energyScore: number; // 0..100 oyun göstergesi
  waterScore: number;  // 0..100 oyun göstergesi
  wellbeing: number;   // 0..100 oyun göstergesi
};
type Choice = { id: string; label: string;
  deltas: Partial<Resources>; tradeoff: string; };
type Scenario = { id: string; version: string;
  baseline: Resources; choices: Choice[];
  learningOutcomeIds: string[]; evidenceRefs: string[]; };
type DecisionResult = { scenarioId: string; choiceId: string;
  before: Resources; after: Resources;
  reasoning?: string; modelVersion: string; };
Saf fonksiyon prototipi
 export function applyChoice(before: Resources, choice: Choice): Resources {
  const next = { ...before };
  for (const [key, delta] of Object.entries(choice.deltas)) {
    const k = key as keyof Resources;
    next[k] = before[k] + (delta ?? 0);
  }
  next.foodWasteKg = Math.max(0, next.foodWasteKg);
  for (const key of ['energyScore','waterScore','wellbeing'] as const)
    next[key] = Math.max(0, Math.min(100, next[key]));
  return next;
}
Bu fonksiyon örnek başlangıç kodudur, tam iklim modeli değildir. Gerçek karbon hesapları için uygun ürün bazlı katsayı ve
yaşam döngüsü kapsamı tanımlanmadan emisyon değeri üretilmez.

Phaser sahnesi - kavramsal iskelet
 class WorldScene extends Phaser.Scene {
  constructor() { super('WorldScene'); }
  preload() {
    this.load.tilemapTiledJSON('world', '/assets/maps/world_alpha.json');
    this.load.image('cityTiles', '/assets/kenney/city/tiles.png');
  }
  create() {
    const map = this.make.tilemap({ key: 'world' });
    const tileset = map.addTilesetImage('TiledCityTileset', 'cityTiles');
    if (!tileset) throw new Error('Tileset adı eşleşmiyor');
    map.createLayer('ground', tileset, 0, 0);
    // roads ve buildings katmanları, sonra hotspots eklenir.
  }
}
